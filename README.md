# Global Seismic Trends – Data-Driven Earthquake Insights

## 📌 Project Overview

This project analyzes global earthquake data to identify seismic patterns, earthquake magnitude trends, depth variations, and geographical distributions.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- MySQL
- Streamlit
- GitHub

## 📂 Project Files

- `USGS.EQK.PY` – Python data analysis and processing
- `app.py` – Streamlit dashboard
- `earthquake_final.csv` – Final earthquake dataset
- `global_eqks.sql` – MySQL database, data loading, and SQL queries
- `requirements.txt` – Required Python libraries

## 📊 Key Analysis

The project includes analysis of:

- Earthquake magnitude
- Earthquake depth
- Geographic distribution
- Latitude and longitude
- Magnitude type
- RMS and GAP
- Number of stations (NST)
- Earthquake types
- Country/location-based earthquake trends

## 🗄️ SQL Analysis

MySQL is used for data storage, cleaning, transformation, and analytical queries.

The `global_eqks.sql` file contains the SQL code used for importing and analyzing the earthquake dataset.

## 📈 Dashboard

A Streamlit dashboard is created to visualize earthquake trends interactively.

## 🎯 Objective

The main objective is to use data analytics and visualization techniques to understand global seismic activity and identify meaningful patterns in earthquake data.
